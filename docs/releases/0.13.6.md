# LCU 0.13.6

**Keeps computer use working in Claude Code on current ChatGPT app builds, whose `js` tool now has two argument forms.**

## Changes

- **Claude Code: `js` is listed again with the new argument forms.** From `@oai/cua-repl` 0.1.3 (ChatGPT `26.1103.31037` on macOS, and later builds such as `26.1103.60933`), the original `js` tool takes either `code` or `completion_summary` alone, written as a top-level `oneOf` in its input schema. Claude Code leaves such a tool out of what it sends to the Claude API, so with tool search off (for example on a model without tool-search support) the model got `js_reset` but no `js`, and computer use stopped working. The Claude Code relay now lists that schema as one object with the fields of every form. Calls reach the original server unchanged, and it still refuses invalid combinations. Other tools are passed through as before. The relay's diagnostic log now records `tool_schema_adapted` for a tool it adapted, and `tool_schema_unsupported` for a tool whose listed schema still has a top-level `oneOf`, `anyOf` or `allOf`, so a tool Claude Code would drop shows up in the log ([#85](https://github.com/amontlabs/lcu/pull/85), [#86](https://github.com/amontlabs/lcu/issues/86), thanks @mdwsk88 for the report and fix, and @aidada for the detailed report).
- **Windows candidate build:** when Windows refuses to remove a temporary directory (for example while antivirus holds a file), the build no longer fails after its work is done, and npm's scratch directory stays out of the archive ([#82](https://github.com/amontlabs/lcu/issues/82), [#84](https://github.com/amontlabs/lcu/pull/84), thanks @Xiao1804 for the report).

Other agents connect to the original runtime directly and are unchanged. OpenCode with Claude models still fails on this schema; that is an OpenCode bug, tracked in [anomalyco/opencode#47543](https://github.com/anomalyco/opencode/issues/47543).

## Upgrading

Run `lcu update`. Claude Code picks up the change the next time it starts the LCU server. To go back, reinstall 0.13.5.
